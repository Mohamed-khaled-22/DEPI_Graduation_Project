# ✈️ Al-Qalada International Airport Portal (بوابة مطار القلادة الرقمية)

### 🌐 Premium Interactive Frontend Web Application (بوابة سفر رقمية ذكية متكاملة)

---

## 🌍 باللغة العربية / Arabic

هذا المشروع هو عبارة عن بوابة إلكترونية تفاعلية متكاملة لمطار دولي ذكي (Front-End) تم بناؤه وتطويره باستخدام مكتبة React مع بيئة التطوير السريعة Vite. يقدم التطبيق واجهة مستخدم ديناميكية فائقة الجمال والرفاهية تحاكي الأنظمة الرقمية الحقيقية للمطارات الذكية العالمية.

---

### 🌟 المميزات والخصائص البرمجية المطورة (Core Features & Pages)

#### 1. الصفحة الرئيسية (Home Page) 🏠

* طقس ووقت الرياض التفاعلي: يعرض ساعة حية تحدث بالثانية بالإضافة إلى حالة طقس مطار الرياض (درجات الحرارة والرموز التعبيرية للطقس).
* شريط الرحلات الفورية (Live Flight Ticker): شريط متحرك يعرض آخر مستجدات صعود الطائرات والرحلات الهامة لحظة بلحظة بشكل مباشر وديناميكي.
* قائمة مهام السفر التفاعلية: ويدجت ذكي يتيح للمسافر تحديد المهام المنجزة قبل الرحلة (مثل فحص الجواز، تجهيز الحقائب) ومتابعة نسبة جاهزيته عبر شريط تقدم مئوي متحرك يتفاعل عند الضغط على كل مهمة.
* تعديل الوضع الفاتح التلقائي: غطاء هيرو متدرج فائق النقاء لضمان سهولة وتباين قراءة الخطوط الداكنة بشكل ممتاز.

#### 2. جدول الرحلات المباشر (Flights Board) ✈️

* لوحة الإحصائيات الفورية: بطاقات علوية تعرض إحصائيات الرحلات الإجمالية (عدد الرحلات الكلي، نسبة دقة المواعيد الفورية، عدد الرحلات المتأخرة، وعدد الرحلات التي في مرحلة صعود الطائرة حالياً).
* التصفية السريعة بالشركات: إمكانية تصفية جدول الرحلات فوريًا حسب شركة الطيران (مثل طيران القلادة، الخطوط السعودية، طيران الإمارات، أو مصر للطيران).
* البحث والطقس التفاعلي: إمكانية البحث الفوري، وجلب درجة الحرارة وحالة الطقس الفعلية لكل وجهة طيران دولية ومحلية.

#### 3. دليل الخدمات والنافذة المنبثقة للحجز الذهبي (Services Page) 🛍

* خدمات جديدة VIP: إضافة خدمات جديدة مثل "المرور السريع VIP" لتخطي طوابير الجوازات، و"ليموزين المطار الفاخر بسائق خاص".
* نظام الحجز الذهبي التفاعلي: عند النقر على حجز الخدمات الفاخرة، يظهر نموذج إدخال بيانات تفاعلي، وعند التأكيد يتم توليد قسيمة حجز ذهبية فاخرة تحمل رقم حجز عشوائي، واسم المسافر، وتاريخ السفر، بالإضافة إلى باركود و كود QR Code تفاعلي للاحتفاظ بالبطاقة.
* سلة تسوق السوق الحرة المسبق: إمكانية اختيار سلع السوق الحرة الفاخرة وإضافتها للسلة لحساب المجموع التلقائي المستحق عند كاونتر الاستلام.

#### 4. خريطة المطار ومكتشف البوابات التفاعلي (Terminal Map) 🗺

* مكتشف البوابة الذكي بالرحلة: يتيح للمسافر إدخال رقم رحلته (مثل QA-301)، لتقوم الخريطة تلقائياً بالانتقال للصالة الصحيحة وتلوين البوابة المحددة، وعرض مسار السير خطوة بخطوة من الفحص الأمني للجوازات إلى البوابة، مع عرض وقت المشي التقريبي المقدر بالدقائق!

#### 5. إصدار البوردنج وبطاقات الأمتعة (Web Check-in) 🎫

* صالونات الطائرة المتنوعة: إمكانية الاختيار بين الدرجة السياحية، درجة الأعمال VIP، أو الدرجة الأولى، وتحديث خريطة وتخطيط المقاعد ديناميكياً بناءً على ذلك (توزيع المقاعد من 2-2 للأعمال، 3-3 للسياحية، 1-1 للأولى).
* مولد بطاقات الأمتعة الذكية (Luggage Tag Generator): بعد قص البوردنج بنجاح، تتاح خطوة إضافية لتوليد كرت حقائب تفاعلي يحمل باركود الأمتعة والوزن المسموح والرمز المرجعي.

#### 6. دليل معلومات السفر ومستشار الفيزا (Travel Guide) 🧳

* حاسبة الأمتعة المرئية التفاعلية: تمثيل رسومي أنيق للحقائب المسموحة، يتغير لون الحقائب وحالتها (لون أخضر للمجاني المسموح، وأحمر للتنبيه بالحقائب الزائدة وقيم رسومها الإضافية).
* مستشار التأشيرات التفاعلي: قائمة منسدلة يختار منها المسافر وجهته لتعرض له التفاصيل الكاملة للتأشيرة المطلوبة والمستندات اللازمة وفترة الإصدار فوراً.

#### 7. شاشات المصادقة والدخول والأمان (Authentication & Contact) 🔐📞

* مؤشر الدعم الحي النابض 🟢 يعطي إحساس بالنشاط الفوري لخدمة العملاء.
* ويدجت تقييم تجربة المطار بالنجوم: نظام تقييم مبهر وتفاعلي بالكامل.
* تسجيل الدخول الذكي بمسح جواز السفر: محاكاة مسح الجواز الرقمي عبر زر تفاعلي يولد شعاع ليزر أخضر يتحرك فوق بطاقة الدخول لملء الحقول تلقائياً وتسجيل الدخول بلمسة تقنية مستقبلية.

---### ⚙️ إدارة الحالة العامة والثيمات (Global State Management):
يستخدم المشروع تقنية Context API لإدارة وتوزيع البيانات ديناميكياً:

1. إدارة اللغات (`LanguageContext`): دعم اللغتين (العربية والإنجليزية) مع التبديل التلقائي الفوري لاتجاه ومحاذاة العناصر (RTL/LTR).
2. إدارة الثيم (`ThemeContext`): تبديل سلس لمظهر الموقع ديناميكياً بين الوضعين الداكن والفاتح مع حفظ تفضيلات المستخدم في المتصفح (localStorage).
3. إدارة المستخدمين (`AuthContext`): محاكاة تسجيل مستخدمين متكامل وحفظ جلسات المستخدم النشط.

### 🛠 التقنيات المستخدمة (Tech Stack)

* React.js (v19)
* Vite (بيئة عمل فائقة السرعة)
* Vanilla CSS & Flexbox/Grid (تصميم واجهة متطور بالكامل دون استخدام مكتبات جاهزة لضمان سرعة التحميل والتوافق الكامل والجمالي).
* React Router Dom (v7) (للتنقل الفوري واللحظي بين الصفحات دون إعادة تحميل الصفحة).
* Lucide-React (أيقونات فيكتور حديثة وتفاعلية).

## 🇬🇧 English / باللغة الإنجليزية

This is a comprehensive, premium virtual portal for a smart international airport, built using React and Vite. The application features premium glassmorphism designs, real-time widgets, interactive layout configurations, and a full bilingual support system.

### 🌟 Key Features

1. Bilingual Support (Arabic/English): Instantly swap languages with full RTL/LTR document alignment.
2. Light/Dark Mode Theme: Toggle smooth themes with localStorage state persistence.
3. Online Web Check-In: Dynamic seat maps per cabin class (Economy, Business, First Class), print-ready boarding passes, and a smart Luggage Tag generator with barcodes.
4. Live Flights Board: Dynamic statistics count, filter by major airlines, and Live Open-Meteo Weather API integration for each destination.
5. Interactive Terminal Map & Gate Finder: Input a flight number to instantly navigate to the gate on the map layout and calculate walking time and paths.
6. Baggage Calculator & Visualizer: Visual bag counter displaying green indicators for allowed bags and red indicators for extra bags with fees.
7. Visa Advisor: Dynamic country selector showing entry visa rules, document checklists, and processing times.
8. Digital Passport Scan Login: Futuristic password scanning simulation using animated laser sweeps to autofill credentials.
